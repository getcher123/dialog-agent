Voice Agent RAG MVP

Голосовой агент в реальном времени с общей базой знаний

Голосовой триггер здесь автоматический: говорите фразу и делайте короткую паузу. После паузы backend запускает STT, retrieval, LLM и TTS. Markdown knowledge индексируется в общий Qdrant-контур и сохраняется для следующих сессий.

Нажмите Старт. Триггер сработает автоматически после паузы в речи.
